# Хомяк-компаньон — UI spec v1 (2026-10-26)

Заменяет вомбата во всех местах, где сейчас `WumbiMood` / `UIWumbi` / `UIWumbiLook`. Статичные SVG, без Rive/Lottie. Тон — тёплый и спокойный. Дашборд — компаньон-строка (решено ранее).

---

## 0. Что берём у других приложений

| Приложение | Что работает | Берём | Не берём |
|---|---|---|---|
| **Duolingo (Duo)** | Маскот реагирует на действие сразу; воплощает главную метрику (серия); большие праздники редкие и по масштабу достижения; смягчает пустые экраны и ошибки | Мгновенная реакция на действие; хомяк = «лицо» главной метрики (запас); праздник по масштабу | Пассивную агрессию и вину за пропуски («Duo грустит»), давление серией |
| **Finch** | Питомец растёт от *поведения*, а не от результата; никогда не наказывает | Эмоция зависит от **тренда и поведения относительно себя**, а не от абсолютной суммы | — |
| **Cleo** | Инсайты человеческим языком, с характером | Короткие фразы-выводы из реальных цифр | «Roast»-режим, сарказм про траты |
| **Headspace** | Спокойные персонажи, ноль тревоги | Спокойная палитра реакций, плохое — мягко | — |
| **Monzo / Revolut** | Данные первичны, интерфейс чистый | Хомяк не закрывает цифры, а объясняет их | — |

Главный вывод: **хомяк — интерпретатор цифр**. Каждая его эмоция и фраза отвечает на «что это значит для меня сейчас?» и, если новость плохая, предлагает одно действие.

**Справедливость:** эмоция считается относительно собственной базы пользователя (его средние расходы, его прошлый месяц), не от абсолютных сумм. Человек с маленьким доходом не должен всегда видеть грустного хомяка.

## 1. Правила появления

1. **Один хомяк на экран.** Всегда в одном и том же слоте этого экрана. Меняется только эмоция (и текст).
2. **Слоты** (тип слота фиксирован за экраном):
   - **Companion** — хомяк 64–72 px + пузырь с текстом. Только дашборд и Progress.
   - **Corner** — хомяк 45 px в правом верхнем углу контента (текущая позиция `UIWumbiLook`). Пузырь появляется сам только для важного, иначе — по тапу.
   - **Empty** — крупный (130–160 px) по центру пустого состояния. **Если экран пустой, corner/companion скрыт** — empty-хомяк его заменяет.
   - **Moment** — хомяк в модальном листе (подтверждение аномалии и т. п.). Модалка перекрывает экран → правило «один» соблюдается.
3. **Формы без хомяка**: Transaction, Wallet form, Budget form, New debt, Debt transaction, Base currency, Language. Это инструменты; подсказки там — только текстом.
4. **Реакция на действие показывается на экране, куда пользователь вернулся.** Сохранил доход → вернулся на дашборд → хомяк `catching` 2.5 с → возвращается к состоянию.
5. **Смена эмоции**: cross-fade 180 мс + лёгкий pop (scale 0.94→1). Без Rive, только трансформации Flutter. (Подтвердить — вопрос 2.)
6. `showMascot = off` → хомяк скрыт, **но текст инсайта остаётся** простой строкой. Польза не зависит от картинки.

- `facepalm` (s1#15) — только опционально для **собственных ошибок приложения** («Ой, это я напутал»), никогда на действия пользователя.
- `noWalletYet` (s2#20) — дубль `idle`.
- `cheeksEmpty` (s2#7) — читается как `happy`, уровень щёк не различим → вместо него `sigh` / `pouchOpen`.
- s2#8 SAVING (монета) — дубль s1#4 и нарушает метафору семечек.

## 3. «Мозг» — откуда эмоция и текст

### 3.1 Сигналы
- **Запас (щёчки)** = баланс учитываемых кошельков − обязательства ближайших 30 дней (подписки, долги «я должен» со сроком, остатки бюджетов). Выражается в **месяцах собственных расходов** (среднее за 3 мес.): `< 0.5` мало, `0.5–3` норма, `≥ 3` полные.
- **Поток месяца** = доход − расход с начала месяца, и темп против прошлого месяца на тот же день.
- **Бюджеты**: превышен / ≥ 80 % при < 80 % периода / в норме.
- **Долги**: просрочка, срок ≤ 3 дней.
- **Подписки**: списание ≤ 3 дней, подорожание.
- **Активность**: дни без записей, дни с прошлого визита.
- **События** (одноразовые): рекорд месяца, бюджет закрыт в лимите, долг погашен, годовщина, крупный доход.

### 3.2 Сообщение
Каждое правило: `условие → приоритет → эмоция → шаблон текста → действие (опц.) → cooldown`.

Приоритет: **реакция на действие** > **предупреждение** (просрочка, превышение) > **событие** (праздник) > **что изменилось с прошлого визита** > **инсайт** > **совет** > **приветствие/связь** > **итог**.

### 3.3 Частота (дашборд — «каждое открытие новое»)
- На каждое открытие берётся **следующее по приоритету непоказанное** сообщение.
- Один смысл не повторяется, пока не изменились данные за ним (хеш условия) или не прошёл cooldown (инсайт 7 дн., совет 14 дн., приветствие 1 день).
- Когда очередь пуста — `итог` (всегда валиден): «В октябре ты пока в плюсе на 420 €».
- Предупреждение держится, пока проблема актуальна, но текст чередуется (2–3 варианта).

### 3.4 Правила текста
- ≤ 2 строк (~80 символов), **максимум одно число**.
- Первое лицо, на «ты», тепло: «Я заметил…», «Давай посмотрим…».
- Никаких «ты должен», «опять», «снова», сарказма о тратах.
- Плохая новость → всегда действие («Посмотреть», «Напомнить», «Разложить»).
- Расход сам по себе — никогда не повод для грусти.
- Локализация шаблонами ICU, пишутся под каждый язык, не переводятся дословно.

### 3.5 Память (локально)
Время последнего визита, история показанных сообщений (id + хеш + дата), достигнутые вехи, ответы на вопросы хомяка, «помолчать сегодня».

## 4. Экраны

### 4.1 Splash
Без хомяка (логотип). Прекеш всех SVG как сейчас.

### 4.2 Onboarding
| Шаг | Эмоция | Текст (пример) |
|---|---|---|
| Welcome | `wave` | «Привет! Я буду присматривать за твоими семечками» |
| Benefit(ы) | `thinking` / `sorting` / `calendar` по теме слайда | — |
| Currency | `counting` | «В чём будем считать?» |
| Wallet | `pouchOpen` → после ввода `saving` | «Где лежат деньги? Начнём с одного кошелька» |
| Final | `celebrate` | «Готово! Заглядывай — я расскажу, как дела» |

Опционально: шаг «Как меня зовут?» (вопрос 1).

### 4.3 Dashboard — Companion
```
☰                              🔍
(хомяк 72)  «Ты в плюсе на 420 € за
             октябрь. Щёчки в норме»   [Посмотреть ›]
            2 340,50 €
      октябрь: +1 400 € · −980 €        ← вместо «N кошельков»
[ Кошельки | Бюджеты | Долги ]
```
- Текущий peek (`UIWumbiLooksFromLeft`) удаляется.
- Пузырь всегда виден; тап по пузырю → действие; тап по хомяку → `love` 1 с + следующее сообщение из очереди (макс. 3 за сессию, потом «Пока всё, что знаю 🙂»). Long-press → «Помолчу сегодня».

**Состояние** (первое сработавшее):
| # | Условие | Эмоция | Пример |
|---|---|---|---|
| 1 | Просроченный долг | `alert` | «Срок по долгу Ахмеду прошёл 3 дня назад» → Открыть |
| 2 | Бюджет превышен | `stop` | ««Еда» вышла за лимит. Посмотрим?» |
| 3 | Бюджет ≥ 80 % раньше 80 % периода | `nervous` | «На «Кафе» осталось 30 € до конца месяца» |
| 4 | Нет записей ≥ 5 дней | `sleep` | «Я задремал — давно ничего не записывали. Добавим вчерашнее?» → + |
| 5 | Поток < 0 и запас < 0.5 мес. | `sigh` | «Месяц пока в минусе. Глянем, что выросло?» → Progress |
| 6 | Непоказанное событие | `victory` / `proud` | «Запас на 3 месяца! Можно спать спокойно» |
| 7 | Запас ≥ 3 мес. | `reserveFull` | «Щёчки полные — запаса на 3 месяца» |
| 8 | Поток > 0 | `happy` | «Ты в плюсе на 420 € за октябрь» |
| 9 | Ничего примечательного | `calm` | «Всё спокойно. Траты как обычно» |
| — | Первое открытие за день (поверх 7–9) | `wave` | «Доброе утро!» + итог |
| — | Возврат после ≥ 7 дней (поверх 4–9) | `wave` | «Рад тебя видеть! С прошлого раза: 3 траты, +2 000 €» |

**Реакции** (2.5 с, затем состояние): доход → `catching` («Поймал 2 400 €!»), крупный доход (≥ среднего месячного) → `cheeksStuffed`, расход → `tossing` (без текста или нейтрально), перевод → `handing`, долг закрыт → `dusting`, первый кошелёк → `celebrate`, бюджет создан → `thumbsUp`.

**Пусто (нет кошельков)**: companion скрыт, Empty `pouchOpen` + CTA «Новый кошелёк».

**Курс не загрузился**: строка-подпись под суммой уже ретраит по тапу; хомяк `shrug` только если это единственная новость.

### 4.4 Side menu
Сейчас peek-вомбат. Вариант А: убрать (рекомендую — меню перекрывает дашборд, где уже есть хомяк). Вариант Б: перерисовать `peekRight/peekLeft` для хомяка и скрывать companion при открытом меню. Вопрос 3.

### 4.5 Transaction — без хомяка
Исключение **Moment**: при сохранении расхода, который в ≥ 3 раза больше обычного для метки (или на порядок больше среднего чека), — лист с `thinking`:
«Это в 3 раза больше обычного для «Кафе». Всё верно?» `[Да, разовая]` `[Исправить]`
«Разовая» помечается и не портит инсайты/привычки. Ловит лишний ноль и даёт ощущение заботы.

### 4.6 Transfer sheet
Нет второго кошелька → Empty `pouchOpen`. Вкладка Debts без долгов → `handing` «Одолжить кому-то?».

### 4.7 Wallet details — Corner
| Условие | Эмоция | Пузырь (авто) |
|---|---|---|
| Баланс < 0 | `nervous` | «Кошелёк ушёл в минус» |
| −30 % с начала месяца | `sigh` | по тапу |
| Накопительный и вырос | `saving` | «+150 € с начала месяца» |
| Нет операций 30 дн. | `sleep` | по тапу «Кошелёк спит» |
| иначе | `idle` | — |
Пустая история → Empty `sleep` «Здесь пока тихо» + «Добавить» (corner скрыт). Не найден → `confused`.

### 4.8 Budgets — Corner
Есть превышение → `stop`; есть ≥ 80 % → `nervous`; все в норме → `calm`. Пусто → Empty `kindly` «Бюджет — это просто лимит. Давай заведём первый?».

### 4.9 Budget details — Corner
Превышен → `stop` «Перебор 40 €. В следующем периоде можно поднять лимит»; темп выше плана → `nervous` «При таком темпе лимит кончится 24-го»; период закрыт в лимите → `proud` (раз); без трат → Empty `sleep`.

### 4.10 Budget form — без хомяка
Текстовая подсказка лимита: «Обычно на «Еду» уходит ~320 € в месяц».

### 4.11 Debts — Corner (в header)
Просрочка → `alert`; срок ≤ 3 дн. → `calendar`; всё погашено (были долги) → `dusting` «Все долги закрыты!»; иначе `idle`. Нет долгов вообще → Empty `thumbsUp` «Никаких долгов. Красота» (сейчас `celebrate` — слишком громко).

### 4.12 Debt details — Corner
Просрочен → `alert` «Срок прошёл 3 дня назад. Напомнить?» → Remind; дал в долг → `handing`; взял со сроком → `calendar`; погашен → `dusting`; прощён → `love`.

### 4.13 Subscriptions — Corner
Основное → `wheel` «6 подписок крутятся: 54 € в месяц»; списание ≤ 3 дн. → `calendar` «Завтра спишется 9,99 €»; подорожала → `thinking` «Подписка подорожала на 2 €». Пусто → Empty `sleep`.

### 4.14 Progress — Companion (первый блок над карточками)
«Вывод периода» одной фразой:
- сэкономил больше базы → `proud` «Лучший месяц за полгода: отложил 520 €»
- в плюсе → `happy`; в минусе → `sigh` «Потратил на 180 € больше дохода, в основном «Кафе»»
- текущий период не закончен → `counting` + прогноз
- есть сильная привычка → `thinking` «По пятницам тратишь вдвое больше»
Нет данных → Empty `sleep` (как сейчас).

### 4.15 Tags — Corner
`sorting`. Много трат без метки → «12 трат без метки. Разложим?» → фильтр. Иначе по тапу «Больше всего в октябре — «Кафе»». Пусто → Empty `sorting` + CTA.

### 4.16 Tag details — Corner
Рост к базе → `thinking` «+40 % к прошлому месяцу»; снижение → `thumbsUp`; без трат → Empty `sleep`.

### 4.17 Search
Пустой запрос / ввод → `searching`; ничего не найдено → `confused`. (Как сейчас.)

### 4.18 Settings / About / Help
Settings — без хомяка (или `hush` в разделе приватности, если появится). About — `love`. Help — `kindly`.

### 4.19 Глобальное
Нет курса / оффлайн → `shrug`. Ошибка приложения → `confused` (или `facepalm` о себе). Бэкап/восстановление успешно → `thumbsUp`.

## 5. Эмоциональная связь

- **Имя** (вопрос 1). Если пользователь даёт имя сам — привязанность выше (эффект тамагочи).
- **Память в речи**: «В прошлом месяце «Еда» была на пределе, сейчас 70 % — лучше!»
- **Годовщины**: 7 / 30 / 100 / 365 дней с ним, 100-я запись → `love` «Спасибо, что записываешь. Вместе считать веселее».
- **Вопросы с кнопками**, которые улучшают данные: «Это разовая покупка?», «Это перевод самому себе?». Ответ = польза + разговор.
- **Тап-реакции**: тап → `love`/`happy` + следующая мысль. Мало, но каждый раз живо.
- **Без вины**: пропуски не наказываются; после паузы — только радость встречи и мягкое «добавим пропущенное?».
- **Уважение**: «Помолчу сегодня» по long-press; настройка «Хомяк говорит».

## 6. Требования к ассетам

1. **Одинаковый холст** у всех SVG (напр. viewBox 512×512), **одна линия земли** (лапы на одном y), один масштаб тела. Иначе при смене эмоции хомяк «прыгает».
2. **Без подписей** — каждая эмоция отдельным файлом. Растры с генератора векторизовать/перерисовать.
3. **Монеты → семечки**: `counting` (s2#10) переделать.
4. **`stop`**: лапа хомяка, а не розовая человеческая ладонь.
5. **Цвета реквизита**: корона, колокол, замок (золото), конфетти, сердца, красный календарь, голубой пот — выбиваются из правила «насыщенный только синий у сумки». Свести к slate + синий; цветное оставить только для `celebrate`/`victory`.
6. **Читаемость на 45 px**: убрать мелочи (пар над чаем, мелкие искры), щёки в `reserveFull` преувеличить.
7. **Тёмная тема**: тёмный контур (#2B3A4F-подобный) теряется на тёмном фоне. Проверить на `colors.bgColor` dark; при необходимости — светлая подложка-круг или вариант контура.
8. **Peek-ассеты** нужны только если оставляем хомяка в меню.

## 8. Решения v1 (реализовано 2026-10-26)

- **Имя**: остаётся «Wumbi» (`WumbiMood`, ассеты `assets/mascot/wumbi_*`), без переименования.
- **Анимации**: cross-fade 180 мс + pop 0.94→1 (`UIWumbi`), drop-in corner сохранён.
- **Side menu**: хомяк убран.
- **Anomaly Moment (§4.5)**: не в этой итерации. Цели накоплений и `hush`-режим — позже.
- **Ассеты**: `reserveFull` = `wumbi_happy_stash` (s1#1), `cheeksStuffed` = `wumbi_cheeks_full` (s2#6), `saving` = `wumbi_saving_seeds`, `wheel` = `wumbi_hamster_wheel`, `hush` = `wumbi_secret`. Неиспользуемые лежат в `assets/mascot/unused/` (не в бандле). Холст не единый — тело нормализуется по высоте viewBox (`idle` = 1150), ноги на нижней границе.
- **Код**: `lib/src/features/mascot/` — `domain/mascot_brain.dart` (правила §3–4.3, отбор), `domain/mascot_screens.dart` (§4.7–4.16), `data/mascot_memory.dart` (таблица `mascot_memory`, БД v6), `ui/mascot_phrases.dart` (ICU, 7 языков). DS: `UiMascotCompanion`, `UiMascotCorner`, `UiMascotBubble`.
- **Сессия** = запуск или возврат после ≥ 30 мин в фоне. Тап по хомяку → `love` + следующая мысль (3 за сессию), long-press → «Помолчу сегодня», Settings → «Wumbi говорит».
- **Запас** = (баланс учитываемых кошельков − подписки за месяц − долги «я должен» со сроком ≤ 30 дн. − свободные остатки бюджетов) / средний расход последних полных месяцев (≤ 3; иначе прогноз текущего с 7-го дня).
- **Слот v1.1 (вместо Companion/Corner)**: на всех экранах голова хамстера выглядывает из нижнего левого угла (напротив FAB) — `UiMascotPeek`, выезжает после навигации и при возврате на экран. Тап → хамстер выходит поверх всего приложения (`UiMascotStage`, root overlay, лёгкое затемнение) и говорит в пузыре; тап вне хамстера и пузыря → уходит обратно в угол; тап по хамстеру → следующая эмоция из набора под контекст (`MascotMoods.cycleFor`). Важное сообщение — синяя точка на голове. На dashboard в пузыре есть «Ещё мысль». Фоновые круги (`UiAmbientBackground.enabled = false`) выключены, код оставлен.

## 9. v1.2 — живой хамстер (2026-10-26)

- Голова в углу меньше (104 px). Тап по хамстеру **не меняет эмоцию** — только лёгкий прыжок. Эмоция меняется лишь вместе с тем, что он говорит или делает.
- Сообщение выбирает сам хамстер: новое на каждый вход (сессия = запуск или возврат через ≥ 5 мин) и при каждом возврате на dashboard (≥ 40 с с прошлой мысли). Инсайты, советы и шутки перемешиваются по дню; память не даёт повторять одно и то же. На остальных экранах — пул «состояние + 1–3 совета экрана», каждый визит следующий.
- Вместо «Ещё мысль» — **чат**: справа от хамстера быстрые ответы (сегодня, вчера, неделя, месяц, крупнейшая трата, бюджеты, что скоро платить, кто должен, на сколько хватит запаса, совет, «рассмеши»). Вопрос справа синим, «…», ответ хамстера с подходящей эмоцией и действием.
- **Вечерняя история**: весь день не заходил → вечером `impatient` «Я ждал тебя весь день!» → `sad` «Я скучал…» → `alert` «Запишем сегодняшние траты?» или `sigh` «Поможешь посчитать вместе?» (через день). Голова сама проигрывает эмоции, точка на голове зовёт открыть.

| Эмоция | Когда |
|---|---|
| idle | кошелёк в норме |
| wave | приветствие дня, возврат через неделю, About, совет «переключи кошелёк» |
| happy | месяц в плюсе, ответ «месяц в плюсе», «ничего не потратил сегодня», пятничная шутка |
| reserveFull | запас ≥ 3 мес., ответ про запас, доля сбережений ≥ 20 %, кошелёк растёт, шутка про деревья |
| cheeksStuffed | реакция на крупный доход, шутка про щёки |
| catching | реакция на доход |
| tossing | реакция на расход |
| celebrate | первый кошелёк, онбординг, «вчера без трат» |
| victory | запас на 3 месяца, серия 30 дней |
| proud | лучший месяц, серия 7/14, дневные траты ниже обычного, бюджет закрыт в лимите |
| thumbsUp | бюджет создан, долгов нет, метка подешевела, «все бюджеты в норме», конец месяца «держишься отлично» |
| calm | спокойный итог, прогноз легче обычного, «нечего платить», совет про паузу подписки |

| sorting | траты без меток, частая метка, советы про метки |
| counting | средние траты в день, итог недели (пн), мелкие покупки, ответы «сколько потратил» |
| calendar | списание скоро, срок долга, годовая стоимость подписок, **экран подписок** |
| wheel | доля регулярных платежей ≥ 30 % |
| thinking | (лампочка-идея) рост метки, пиковый день, крупнейшая трата, выходные дороже, нет дохода, совет про перенос остатка бюджета |
| kindly | совет завести бюджет, новый месяц, бюджет для крупной метки, пустые бюджеты, Help |
| searching / confused | поиск / не найдено |
| shrug | нет курса валюты, «мало данных для ответа» |

## 10. v1.3: голос хомяка (2026-10-26)

- Пользователь для Wumbi — «хозяин», большой хомяк, который запасается семечками. Обращение звучит естественно в большинстве реплик, но не в каждой. Аналоги: en *boss*, fr *patron*, de *Chef*, nl *baas*, tr *patron*, ar *سيدي*.
- Деньги в тексте всегда «семечки» (seeds / graines / Kerne / zaadjes / çekirdek / بذور). Суммы показываются цифрой с валютой.
- Словарь: запас, щёчки, мешочек, заборчик (бюджет), укус (трата), утечка. Без канцелярита и «ИИ-гладкости»: короткие фразы, вопрос-предложение в конце вместо приказа.
- Хомяк радуется экономии и росту дохода. При перерасходе он не стыдит хозяина, а предлагает разобраться вместе.
- Новые реплики, основанные на исследованиях денежной тревожности (Allianz «3am Report», YNAB «Mood on Money», The Decision Lab, nudges):

| Ключ | Триггер | Эмоция |
|---|---|---|
| `tip_rainy_day` | один кошелёк, нет подушки | kindly |
| `tip_pay_yourself_first` | доход пришёл ≤ 1 дня назад | saving |
| `insight_income_up` | доход выше среднего | reserveFull |
| `insight_tag_yearly` | топ-метка × 12 | thinking |
| `tip_future_self` | 5 ед./день × 365 | thinking |
| `tip_treat` | запас в норме, «можно без вины» | happy |
| `insight_no_spend_yesterday` | вчера ноль трат | proud |
| `q_where` / `ans_where*` | «Куда ушли семечки?» (топ-2 метки или доля без меток) | thinking |
